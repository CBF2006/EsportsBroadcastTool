# EsportsBrodcastTool
A package that allows you create professional esports productions for free!

## WORK IN PROGRESS - DETAILS TBD
How do the professional tournaments create such good productions? The secret is they host all the graphics online.

How can I do it like them? All you need is this package and a Google account.

Simply make a copy of the google sheet, download and host your own browser sources with many free online hosting platforms, and add put the urls into the browser sources, it's that easy!
